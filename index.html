    How the project works

    DSA concepts are used behind the analysis process.

    1. Extract

    Resume and job-description text is collected and normalized for analysis.

    2. Match

    Hash-based keyword lookup and set operations identify common and missing terms.

    3. Score

    The system calculates a keyword-based compatibility percentage and presents suggestions.
